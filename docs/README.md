# Documentation

This folder is for the project blueprint, operational notes, architecture guidance, planning documents, and project-level writeups.

## Recommended files

- `project-overview.md` — high-level purpose and goals
- `architecture.md` — system design and boundaries
- `roadmap.md` — development plan and milestones
- `runbook.md` — operational procedures and troubleshooting

## Guidance

Keep documents concise, useful, and easy to reference for future contributors or later review.
